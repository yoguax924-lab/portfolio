【画像の置き場所と命名規則】

このフォルダ(images)に画像を入れます。
書き換える場所は works-data.js だけです。

--------------------------------------------------
■ 基本ルール
--------------------------------------------------
・使える文字 : 半角の小文字英数字 と ハイフン(-) だけ
・使えない   : 日本語、スペース、大文字、アンダースコア
・拡張子     : 小文字で .jpg に統一（透過が必要なときだけ .png）
・番号       : 2桁の連番（01, 02, 03 ...）

--------------------------------------------------
■ 命名パターン
--------------------------------------------------
トップのスライド
    slide-01.jpg, slide-02.jpg, slide-03.jpg ...

作品のサムネイル（一覧に出る画像）
    {作品ID}-thumb.jpg
    例) work-01-thumb.jpg

作品詳細ページの写真
    {作品ID}-{連番}.jpg
    例) work-01-01.jpg, work-01-02.jpg, work-01-03.jpg

※ {作品ID} は works-data.js の id と同じ名前にします。
  こうすると、どの画像がどの作品のものか一目で分かります。

--------------------------------------------------
■ works-data.js への書き方（例）
--------------------------------------------------
スライド
    { caption: "Work 01", image: "images/slide-01.jpg", bg: "..." },

作品
    image:  "images/work-01-thumb.jpg",
    photos: ["images/work-01-01.jpg", "images/work-01-02.jpg"],

--------------------------------------------------
■ サイズの目安
--------------------------------------------------
・スライド     : 横1920px前後 (16:9)
・サムネイル   : 1280x720 (16:9)
・詳細の写真   : 横1600px前後 (3:2 だと枠にぴったり)
・容量         : 1枚 500KB〜1MB 程度に圧縮（表示が速くなります）
※ 枠に合わせて自動で切り抜かれます。
